# Zeta Car 🏎️

3D-style town racing game for Android. Coins, shop, car upgrades, day/night cycle.

## GitHub එකට දාන විදිහ
1. GitHub එකේ අලුත් repo එකක් හදන්න.
2. මේ folder එකේ ඇති හැම file එකක්ම (`.github` folder එකත් එක්ක) upload කරන්න.
3. **Settings → Actions → General → Workflow permissions → Read and write** දාන්න.
4. Commit කළාම **Actions** tab එකේ build එක ඉබේම පටන් ගන්නවා. ඉවර වුනාම **Releases** වල `ZetaCar.apk` එක තියෙනවා.

## Controls
- ◀ ▶ : steer (keyboard: arrows / A D)
- 🔥 NITRO : boost (keyboard: Space)

Game එක `app/src/main/assets/index.html` ඇතුළේ.
